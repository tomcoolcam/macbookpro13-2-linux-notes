# Selected evidence

`selected-trace.txt` retains suspend phase timestamps and selected AML entry
paths. Process names, PIDs, CPUs and task flags were omitted.
`tb-methods.txt` lists decoded Thunderbolt AML calls, paired outer returns and
original private trace line numbers. PIDs were removed and the root name normalized.
Neither file is the complete trace. PCI addresses and ACPI paths identify device
topology, not individual machine serial numbers. No network identifiers are included.
